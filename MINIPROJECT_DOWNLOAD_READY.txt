🚀 THREE WAYS TO USE THIS PROJECT
════════════════════════════════════════════════════════════════════════════

OPTION 1: DOCKER COMPOSE (Recommended for immediate deployment)
───────────────────────────────────────────────────────────────
1. Extract ZIP file
2. cd fullstack
3. docker-compose up -d
4. Open: http://localhost:5000
✅ Best for: Production, quick deployment, all dependencies managed

OPTION 2: DIRECT PYTHON (Best for development & learning)
──────────────────────────────────────────────────────────
1. Extract ZIP file
2. cd fullstack
3. python3.10 -m venv venv
4. source venv/bin/activate (or .\venv\Scripts\activate on Windows)
5. pip install -r requirements.txt
6. python backend/app.py
7. Open: http://localhost:5000
✅ Best for: Development, modification, learning

OPTION 3: CLI (Best for terminal users & automation)
────────────────────────────────────────────────────
1. Extract ZIP file
2. Main directory setup
3. python main.py config
4. python main.py train --train-dir data/train/
5. python main.py inference --image-dir data/test/
✅ Best for: CLI enthusiasts, scripts, batch processing
